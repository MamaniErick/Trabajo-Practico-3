# Documentación Técnica – Mega Turismo 

# Introducción 
Mega Turismo es un sitio web desarrollado como parte del Trabajo Práctico de la 
asignatura, aplicando tecnologías modernas de desarrollo frontend como HTML5, 
CSS3, Bootstrap 5 y jQuery. 
El objetivo principal del proyecto fue construir una plataforma web responsive, 
interactiva y visualmente atractiva para una empresa de turismo, incorporando buenas 
prácticas de diseño, usabilidad y programación. 
El sitio se adapta correctamente a múltiples dispositivos, incluyendo teléfonos móviles, 
tablets, computadoras de escritorio y pantallas de gran tamaño. 
Tecnologías Utilizadas 
● HTML5  
● CSS3  
● Bootstrap 5  
● JavaScript  
● jQuery  
● Bootstrap Icons  
● CSS Sprite  
● Git y GitHub  
● GitHub Pages 
Objetivos del Proyecto 
●  Desarrollar un sitio web completamente responsive.  
●  Aplicar componentes y utilidades de Bootstrap.  
●  Implementar interactividad mediante jQuery.  
●   Utilizar iconografía moderna y sprites CSS.  
●   Incorporar validaciones de formularios.  
●   Simular un módulo educativo sobre phishing.  
●   Publicar el proyecto en línea mediante GitHub Pages. 
Estructura del Sitio 
El proyecto se encuentra organizado de la siguiente forma: 

# Barra de Navegación (Navbar): 
La barra de navegación es la misma para cada página y fue desarrollada utilizando 
Bootstrap 5, lo que garantiza un diseño moderno, adaptable y completamente 
responsive. Incluye un logotipo identificativo, enlaces de navegación hacia las 
diferentes secciones del sitio y un menú desplegable automático para dispositivos 
móviles. Asimismo, incorpora el botón de alternancia del modo oscuro, integrando 
funcionalidad y accesibilidad en un único componente. Su posición fija en la parte 
superior facilita el acceso permanente a las distintas páginas del sitio. 
El navbar contine el Modo Oscuro desarrollada mediante JavaScript, CSS3 y 
almacenamiento local utilizando LocalStorage. Esta característica permite al usuario 
alternar entre el tema claro y oscuro mediante un botón interactivo ubicado en la 
barra de navegación. La preferencia seleccionada se guarda automáticamente en el 
navegador, manteniéndose activa en futuras visitas. Además, se implementó un 
cambio dinámico del icono utilizando Bootstrap Icons, mejorando la experiencia visual 
e interacción del usuario. 
# Pie de Página (Footer): 
El pie de página fue diseñado con HTML5, CSS3 y componentes de Bootstrap, 
proporcionando una estructura ordenada y adaptable. Para la página Index fue 
diseñado en tres columnas principales: 

Newsletter que incluye un formulario de suscripción con validación HTML5, 
expresiones regulares para verificar correos electrónicos con retroalimentación visual 
inmediata.  

Ubicación en el cual se integró un mapa interactivo de Google Maps mediante iframe, 
mostrando la ubicación de la empresa.  

Y finalmente la tercera columna que también usan las demás páginas, esta incluye 
enlaces a las principales redes sociales mediante la técnica de CSS Sprite, optimizando 
la carga de imágenes y mejorando el rendimiento general del sitio. Además, presenta la información 
de derechos de autor y mantiene una distribución responsive que se adapta correctamente a cualquier
tamaño de pantalla, ofreciendo una apariencia profesional y consistente en todas las páginas. 

# INDEX: 
La página principal constituye la portada del sitio web y representa el punto de entrada para 
los usuarios. Fue diseñada con un enfoque visual moderno, priorizando la experiencia del 
usuario, la navegación intuitiva y la adaptabilidad a múltiples dispositivos. 
Sección Hero 
La portada cuenta con una sección Hero de alto impacto visual, compuesta por: 
- Video de fondo en reproducción automática. 
- Capa superpuesta semitransparente para mejorar la legibilidad. 
- Título principal destacado.
- Subtítulo descriptivo. 
- Botón de llamada a la acción que redirige a la sección de destinos.

Destinos Destacados 
Se desarrolló una galería de destinos utilizando Cards de Bootstrap organizadas 
mediante el sistema Grid. 
Cada tarjeta incluye; Imagen representativa, Nombre del destino, Breve descripción. El 
diseño es completamente responsive y se adapta automáticamente a distintos 
tamaños de pantalla. 

Testimonios 
La página incluye un carrusel personalizado de testimonios de turistas. Sus 
características principales son desplazamiento horizontal automático, diseño 
adaptable. Ocultamiento en dispositivos pequeños para optimizar el rendimiento y 
presentación clara de comentarios, autores y procedencia. 
Esta sección fortalece la credibilidad del sitio mediante experiencias reales de usuarios. 

# Página de Destinos 
Esta sección del sitio fue diseñada para presentar de manera visual e interactiva los 
principales destinos turísticos ofrecidos por Mega Turismo. Para su desarrollo se utilizó 
HTML5 en la estructura del contenido, CSS3 para los estilos personalizados, Bootstrap 
5 para lograr un diseño responsive y una interfaz moderna. 
Entre las principales funcionalidades implementadas se destacan: 
Banner principal: sección destacada con un título llamativo y una breve descripción 
que introduce al visitante a la experiencia turística ofrecida. 
Sistema de filtrado por categorías: construido mediante botones de opción (radio 
buttons) y CSS, permite visualizar destinos según su categoría: Cultural, Naturaleza, 
Gastronómico y Religioso. 
Galería visual tipo Masonry: presenta los destinos en un formato dinámico y atractivo, 
incorporando efectos hover y superposiciones informativas. 
Tabla de precios responsive: desarrollada con Bootstrap, muestra información 
detallada sobre los paquetes turísticos, incluyendo destino, categoría, duración y 
precio. 
Esta página combina diseño, usabilidad y rendimiento, ofreciendo una experiencia 
intuitiva y atractiva para el usuario al momento de explorar los destinos disponibles.

# Página de Precios 
Esta sección fue desarrollada con el objetivo de presentar de forma clara, organizada y 
atractiva los distintos paquetes turísticos ofrecidos por Mega Turismo. Para su 
implementación se utilizaron HTML5 para la estructura del contenido, CSS3 para la 
personalización visual, Bootstrap 5 para garantizar el diseño responsive y mejorar la 
presentación de los componentes, Bootstrap Icons para incorporar elementos gráficos 
informativos, JavaScript y jQuery para la inicialización y funcionamiento de 
componentes interactivos. 
Entre las funcionalidades principales de esta página se destacan: 
Banner principal informativo: presenta un título destacado y una breve descripción 
que orienta al usuario sobre el contenido de la sección. 
Tabla de precios responsive: muestra de manera ordenada los distintos paquetes 
turísticos, incluyendo destino, duración, servicios incluidos y precio correspondiente. 
Información adicional mediante tooltips: utilizando Bootstrap y JavaScript, se 
incorporaron íconos informativos que permiten visualizar detalles extras al posicionar 
el cursor sobre determinados precios. 
Diseño adaptable a dispositivos móviles: la tabla se ajusta automáticamente a 
diferentes resoluciones gracias a las técnicas responsive implementadas con Bootstrap 
y CSS. 
Organización visual optimizada: la estructura facilita la lectura y comparación entre las 
distintas opciones disponibles, mejorando la experiencia del usuario. 
Esta página permite al visitante consultar rápidamente las tarifas y características de 
cada paquete, brindando una interfaz intuitiva, profesional y completamente 
adaptable a cualquier dispositivo. 

# Página de Agencias 
Esta sección tiene como objetivo presentar de manera clara y visual las distintas 
sucursales o aliados estratégicos de Mega Turismo. 
● Implementación: Se utilizó HTML5 para la estructura, CSS3 para el diseño de 
tarjetas (cards) y Bootstrap 5 para el sistema de rejilla (grid) que garantiza la 
visualización en dispositivos móviles. 
● Funcionalidades principales: 
        ○ Tarjetas de Agencias: Presentación de cada agencia con imagen, 
            nombre y ubicación. 
        ○ Sistema Responsive: La disposición de las tarjetas cambia 
            dinámicamente según el tamaño de la pantalla (1, 2 o 3 columnas).
        ○ Botones de Interacción: Enlaces directos para consultar más 
            información o contactar a cada sucursal. 

# Página de Blog 
Sección diseñada para compartir contenido relevante sobre destinos turísticos, 
consejos de viaje y noticias de interés para los usuarios. 
● Implementación: Se implementó una estructura de artículos utilizando 
componentes de Bootstrap 5, con personalización estética mediante CSS para 
mejorar la legibilidad y el atractivo visual. 
● Funcionalidades principales: 
    ○ Layout de Artículos: Visualización organizada de entradas de blog con 
        fecha, autor y categorías. 
    ○ Sidebars Informativos: Columna lateral para navegación rápida entre 
        temas destacados o publicaciones recientes. 
    ○ Integración Multimedia: Incorporación de imágenes optimizadas que 
        complementan el contenido textual. 

# Página de Contacto 
El objetivo de esta página es facilitar la comunicación directa entre los clientes 
potenciales y el equipo de Mega Turismo. 
● Implementación: Se utilizó un Formulario de Bootstrap 5 integrado con 
JavaScript para la gestión de la interactividad y Regex para la validación de 
datos. 
● Funcionalidades principales: 
    ○ Validación en tiempo real: Uso de scripts para verificar que el correo y 
        el teléfono cumplan con el formato correcto antes del envío. 
    ○ Feedback Visual: Cambio de colores en los campos (verde/rojo) según la 
        validez de la información ingresada. 
    ○ Componentes Interactivos: Inclusión de un spinner de carga y un modal 
        de confirmación tras el envío exitoso de los datos. 

# Módulo Educativo: Phishing 
Esta sección cumple una función académica y preventiva, diseñada para concientizar a 
los usuarios sobre los peligros de los ataques de ingeniería social. 
● Implementación: Se desarrolló una interfaz controlada utilizando Bootstrap 5 
Modals y JavaScript, siguiendo estrictamente la normativa de no permitir el 
robo ni almacenamiento de datos reales. 
● Funcionalidades principales:
    ○ Disparador de Simulación: Botón destacado que inicia la experiencia de 
        aprendizaje. 
    ○ Modal de Advertencia: Ventana emergente que detalla los riesgos de 
        un ataque real de forma clara y directa. 
    ○ Contenido Educativo: Desglose de señales de fraude (URLs falsas, 
        urgencia, remitentes extraños) y ejemplos visuales para que el usuario 
        aprenda a identificar amenazas en el futuro.
